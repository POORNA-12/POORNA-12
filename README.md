## 🚀 Featured Projects

### 🔍 ScopeMap

**Local-first · deterministic · change-impact analysis**

Understand the blast radius of a code change before it reaches production.

ScopeMap is my first open-source project, built around deterministic dependency analysis rather than cloud-based source processing.

#### Highlights

- 🧠 Python AST + optional Tree-sitter parsing
- 🐍 Python · 🟦 TypeScript · 🟨 JavaScript · 🐹 Go
- 🔄 Deterministic reverse-BFS impact analysis
- 📍 Exact line-level evidence
- 🛡️ Architecture boundary guards
- 📊 Interactive HTML / SVG / Bokeh reports
- 🖥️ Terminal interactive explorer
- 🔒 Zero-worktree-mutation branch analysis
- 🤖 GitHub Action + pre-commit integration
- 🧠 AI-agent skill integration

📦 **v0.10.0** · 🧪 **204 tests passed** · 📜 **MIT License**
